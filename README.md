# Searchable & Filterable Product Catalog

A mobile product catalog application built with **React Native** and **TypeScript** that supports real-time keyword search and category-based filtering.

## Features

- **Real-Time Search:** Instant product filtering by name using `TextInput` and state management (`useState`).
- **Category Filtering:** Interactive category tabs (`Tümü`, `Elektronik`, `Giyim`, `Ulaşım`, `Kitap`) built with `Pressable`.
- **Dynamic Result Counter:** Displays the total number of matching products in real time.
- **Empty State Handling:** Shows a clean fallback message (`Ürün bulunamadı.`) via `FlatList`'s `ListEmptyComponent` when no items match the active filters.

## Tech Stack

- React Native
- TypeScript
